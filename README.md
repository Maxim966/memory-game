# Memory Game

Игра на память с 16 карточками и 8 парами. Запуск проекта локально:

```bash
npm install
npm run dev
```

## Компоненты на JavaScript

Разметка приложения создаётся в JavaScript, без HTML-шаблонов и UI-фреймворков.
Общая функция `createElement` из `src/js/createElement.js` создаёт DOM-элемент
по тегу и параметрам: CSS-классу, атрибутам, обработчикам событий, тексту и
дочерним элементам. Её используют для игрового поля, карточек, статистики и
модальных окон. Стили компонентов находятся в `src/scss/`.

## Правила и логика игры

- Игра автоматически начинается при первой загрузке и после перезагрузки.
  Создаются 16 карточек — по две на каждый из 8 фруктов; карточки
  перемешиваются и раскладываются рубашкой вверх.
- Игрок открывает две разные карточки. Открытие второй карточки завершает ход
  и увеличивает счётчик ходов независимо от результата.
- При совпадении карточки остаются открытыми, а счётчик найденных пар
  увеличивается.
- При несовпадении карточки остаются видимыми 1 секунду. Пока они открыты,
  новые карточки выбрать нельзя; затем обе карточки закрываются.
- После нахождения всех 8 пар появляется окно победы с количеством ходов,
  полем для имени игрока, кнопкой сохранения результата, кнопкой новой игры и
  кнопкой закрытия.
- Сохранённые результаты сортируются по количеству ходов, при равенстве —
  по дате, и хранятся в `localStorage` браузера. В таблице лидеров отображаются
  до 10 лучших результатов.

## Управление

- **Новая игра** — перемешивает карточки и сбрасывает счётчики.
- **Таблица лидеров** — показывает сохранённые результаты игроков.

# Memory Game

## Правила и логика игры

* **Старт игры:** Игра начинается автоматически при первой загрузке и каждой перезагрузке страницы. Все 16 карточек перемешиваются и раскладываются рубашкой вверх. Счётчик ходов и найденных пар обнуляются (0 из 8).
* **Игровой ход:** 
  1. Игрок открывает одну карточку, затем другую. 
  2. Один ход считается за открытие двух разных карточек (независимо от результата).
* **Совпадение:** Если изображения совпали, карточки остаются открытыми до конца игры, а счётчик пар увеличивается на 1.
* **Несовпадение:** Если изображения различаются, карточки остаются видимыми около секунды, после чего автоматически закрываются. В этот момент возможность клика по другим карточкам блокируется.
* **Завершение игры:** Когда найдены все 8 пар, появляется модальное окно с сообщением о победе, итоговым количеством ходов и кнопками **«Новая игра»** и **«Закрыть»**.

## Управление и интерфейс

В шапке (хедере) расположены две управляющие кнопки:
* **«Новая игра»** — перезапускает текущую сессию: карточки перемешиваются и закрываются, счётчики сбрасываются.
* **«Таблица лидеров»** — открывает модальное окно с сохранёнными результатами игроков.
